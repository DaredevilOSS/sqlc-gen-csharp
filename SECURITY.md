# Security Policy

## Supported versions
Only the latest release receives security fixes.

## Reporting a vulnerability
Please do not open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/DaredevilOSS/sqlc-gen-csharp/security/advisories/new).

Include the plugin version, a description of the issue, and, where relevant, the schema/query that produces
the problematic generated code (for example, SQL injection or unsafe parameter handling in generated output).
